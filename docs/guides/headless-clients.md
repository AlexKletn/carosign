# Работа с CaroSign без графической оболочки

## Биометрия пользователя

`carosignctl` обращается к `carosignd` через клиентский сокет.

```sh
carosignctl list
carosignctl enroll - "Правый указательный"
carosignctl list enrollments
carosignctl remove <ID-регистрации>
```

В команде `enroll` первый аргумент задаёт учётную запись. Используйте `-`
для текущего пользователя. Если подходящих устройств несколько, добавьте ID
устройства третьим аргументом. Подходит короткий ID из `list`, если он
однозначен. Команда `remove` принимает полный ID из `list enrollments` и
необязательное имя пользователя.

Команды записи и удаления выводят ID операции в stderr сразу после допуска.
При записи туда же выводятся подсказки и прогресс. Команда выдаёт ID
регистрации в stdout после подтверждённой фиксации изменения. Пока операция
выполняется, её можно отменить через `carosignctl cancel <ID-операции>` из
другого терминала и проверить результат через `carosignctl status <ID-операции>`.
Допуск определяется системной политикой. Для работы нужны соответствующие
права на инвентарь и действие для выбранного пользователя.

## Конфигурация и диагностика

```sh
sudo carosign-config show service
sudo carosign-config check policy
sudo carosign-config check providers
sudo carosign-config check profile /etc/carosign/example-provider.conf
carosign-config edit service
sudo carosign-config diagnose
```

Цели `service`, `policy`, `providers` и `profile` соответствуют конфигурационным
файлам службы, политики, обнаружения и профиля. `--config /абсолютный/путь`
задаёт альтернативный файл службы. Для прямого режима путь профиля берётся
из него, а в режиме обнаружения его можно указать явно.

`edit` использует `sudoedit` и проверяет результат после сохранения.
Исправьте ошибки проверки до перезапуска службы. `diagnose` проверяет
настройки, опрашивает службу и отдельно показывает результат запроса
инвентаря от UID, запустившего инструмент. При запуске через `sudo`
для инвентаря проверяются права root. Для конфигурационных файлов после
изменений требуется перезапуск `carosignd`.
