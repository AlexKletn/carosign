# Журналы испытаний GNOME Shell 51.1

Журналы сохранены из испытаний платформы с моковым провайдером на планшете
16 ноября 2026 года. Они перенесены из `TB371FC-linux/out/biometric-platform/`
без изменения содержимого. Журналы описывают конкретные пробы и не заменяют
проверку актуальной версии GNOME или настоящего оборудования.

- `gdm-diagnostic-20261116/` — исходная диагностика экранной аутентификации.
- `gdm-trial-20261116/` — журналы пробы временной правки экрана блокировки.
- `gdm-greeter-trial-20261116/` — журналы пробы начального экрана GDM. В
  `journal.log` зафиксированы ожидание мокового провайдера и открытие сеанса
  пользователя через `gdm-fingerprint` в 03:51:56.

Каталоги содержат разные снимки журналов, даже когда имена файлов совпадают.
Исходники экспериментальных правок и ограничения описаны в
[compat/gnome-shell-51.1](../../../compat/gnome-shell-51.1/README.md).
