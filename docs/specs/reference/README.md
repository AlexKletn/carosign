# Первичные материалы (не нормативная спецификация новой платформы)

Этот каталог добавлен для воспроизводимости решений. Материалы предоставлены пользователем и включены **без редактирования содержания**:

- [`gxfp_user_facing.md`](gxfp_user_facing.md) — системный слой старого GXFP5130 проекта, включая PAM, `gxfp-authd`, хранилище и GUI. Не описывает wire sensor/algorithms.
- [`trust-anchor-auth-biometrics.md`](trust-anchor-auth-biometrics.md) — Veles/Nord4: исследовательский план и модели доверия. **Не** подтверждает завершённую защищённую биометрическую сессию.
- [`goodix-source/fingerprint/README.md`](goodix-source/fingerprint/README.md) — исходное дерево Goodix/TB371FC из tar.gz. Здесь сохранены `stok/` (актуальная спецификация из источника), `tablicy/` (справочные таблицы), `stok/history/` и `archive/` (старые, возможно устаревшие версии) и журналы измерений.

**Приоритет для интерпретации Goodix:** `stok/` + `tablicy/` > журналы измерений > исторические и архивные материалы. Этот приоритет задан в самом источнике.

Архитектура в соседних `architecture/`, `protocols/`, `platforms/`, `providers/`, `engineering/` — **новый предложенный проект**, не буквальная спецификация существующих исходных репозиториев.
