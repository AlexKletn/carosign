## Дыры, закрытые в описании

1. **`1002 EXIT`** — тело **96 байт** (было «?»); шлётся в `gf_hal_common_close`
   перед `gf_ca_close_session` и снятием питания.
2. **`1006 PRE_ENROLL` возвращает challenge** — 8 байт с `+0x60` тела ответа.
   Это то, что HAL отдаёт Android для подписи Gatekeeper.
3. **`1007 ENROLL`**: тело 176 байт, `+0x60` группа, `+0x68` признак дампа,
   `+0x69` ноль, **HAT 69 байт с `+0x6a`**; коды `0x420`/`0x41f` — «аппарат
   недоступен», они гасятся в успех.
4. **Таймер записи**: по сроку — отмена (`1009`) и `notify_error_info(3)`.
5. **`gf_hal_reinit`** — отдельный полный круг: закрыть/открыть сеанс, до
   пяти обнаружений (счётчик только в регистре, **не в теле**), `1001`,
   условный `1004`, `1005`, `1111`, условный `1110`.
6. **Условие `1004` — `config[+4] == 0`**, то есть `body[100] == 0` из ответа
   `DETECT_SENSOR`. Уточняет прежнее «не слать 1004»: это верно для нашего
   значения (`≠0`), но не как общее правило.
7. **Уведомления наружу** — тип `5` (опознание, 69-байтный токен) и тип `9`
   (FIDO, 512 байт).
8. **`uinput`**: `open("/dev/uinput")`, `UI_SET_EVBIT` (EV_KEY),
   `UI_SET_KEYBIT`, `uinput_setup` 1116 байт, имя **`uinput_nav`**. Жест по
   датчику у стока — ещё и эмуляция клавиш.
9. **Таблицы режимов/навигации/операций** найдены в `.data`
   (`0x416fa8`, `0x416808`, `0x4177c8`), но **строки в них пустые** —
   имена не сохранились. Отсюда правило: не называть режимы и операции
   словами, которых нет в двоичном.

## Чего в описании **всё ещё** нет

1. Имён режимов и операций — в образе их нет (см. выше).
2. Раскладки `uidev` для `uinput` (1116 байт) — нужна только для навигации.
3. Полей `1071 NAVIGATE` и `1073` — их тела не выписаны.
4. Смысла `config[0x70]`, `[0x5b]`, `[0x1af]`, `[0x1b0]`, `[0x44]` — по
   вызовам видно, что они означают (предел попыток, дамп, перечисление,
   `MT_BASE`, половина шаблонов), но их значения не читаны.
5. `gf_dump_*` и `frr/far` — только в перечне, без раскладок.

⚠️ Числа из пунктов 1–5 называть «догадкой», пока в двоичном не найдены
строки или замер.
