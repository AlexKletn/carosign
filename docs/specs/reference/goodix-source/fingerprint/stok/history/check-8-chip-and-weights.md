## Что не закрылось — и честно помечено

1. **Имя символа для вида `0`** у чипа `0x2e`. Ветвь видна, константа
   `0x238ed` слов видна, но **взята из GOT** — надо прочитать слот и
   сверить с `readelf -rW`. Крупный кандидат — `DLWeightLightDubaiB16BIT`,
   но это **не доказано**.
2. **Счёт не сходится:** `0x238ed` слов = 582 324 Б, а символ 582 580 Б.
   Разница 256 Б — либо хвост у символа, либо число слов не про него.
3. **Позиция таблицы прыжков** в файле не подтверждена (36.2a): по
   `0xa96f4` набор смещений не согласуется с кодом.

## Ошибка, которую пришлось исправить трижды

Адреса в этом образе различаются для `.text` и `.data`, и я спутал их
дважды:

* сначала читал `.text` с `+0x10000` (мусор);
* потом написал «читай по файловому смещению» — и это верно только для
  `objdump -d` **по всему файлу**, но не для ручной нарезки.

✅ Правило: **`objdump -d <файл> --start-address=<адрес из nm>`**.
Для ручной нарезки `dd` нужен пересчёт через заголовки программ.

функцией. Поэтому дальше — только `objdump` по целому файлу.
