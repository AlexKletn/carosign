## Найдено новое

1. **`1091` — не безусловная.** Пауза и возобновление записи идут только
   при `config[0x1af] == 0` **или** `power_down_flag != 1`; иначе печать
   `pause enroll skip` и тишина. Тела: пауза `1`, возобновление `0`.
2. **`1111` не константа по числу слов.** Веса и их число готовит
   `FUN_001635c8`; `0x238ed` — частный случай серии 46. Есть второй путь
   (`config[+0x184]`) с повторным заполнением.
3. **`uinput` отправляет `input_event` 24 байта**: время `+0`, тип `+0x10`,
   код `+0x12`, значение `+0x14`.
4. **Интервалы навигации сток ограничивает**: `config[0x3c]` в `0x50…1000`
   иначе `300`; `config[0x40]` в `600…2000` иначе `700`.

## Важное предупреждение про догадки

Уже дважды таблицы стока (режимы, навигация, операции) оказывались с
**пустыми строками**. Поэтому в 17–23 имена не выдумываются: где имя не
найдено в двоичном, стоит число и пометка.
