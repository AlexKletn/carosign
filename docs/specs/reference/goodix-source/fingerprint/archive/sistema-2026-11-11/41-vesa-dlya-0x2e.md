# 41 — Пробел №1 закрыт: веса для `0x2e` ✅BIN

Таблица переходов прочитана и **сошлась с кодом**. Ошибка прошлых заходов
была одна: цель считается не от адреса `add`, а от `x8`, где уже лежит
**адрес таблицы** (`0xa96f4`), и смещения — **32-разрядные**, а не
масштабируемые ×4.

## 41.1 Механика ✅BIN

```
63668: adrp x8, a9000
6366c: add  x8, x8, #0x6f4        → x8 = 0xa96f4   (СТАРТ таблицы)
63670: ldr  x9, [sp, #40]         → w9 = chip − 0x16
63674: ldrsw x10, [x8, x9, lsl #2]
63678: add  x8, x10, x8           → target = 0xa96f4 + offset
6367c: br   x8
```

⚠️ Прошлые попытки давали мусор, потому что я считал `T + off×4` и/или
брал базу `0x6366c`. Правильно: **база = `0xa96f4`, прибавка = `off` один
раз**.

## 41.2 Куда ведёт каждый чип

| чип | цель | ветвь |
|---|---|---|
| `0x16` (код `22`) | `0x637a0` | своя |
| `0x2b` (3626ZS1) | **`0x63680`** | 16-битная |
| `0x2c` (3636ZS1) | `0x63800` | выход с ошибкой |
| `0x2d` (3988) | `0x636e0` | 8-битная |
| **`0x2e` (3956 — наш)** | **`0x63680`** | **16-битная** |
| `0x2f` (5658ZS3) | `0x63800` | выход с ошибкой |
| `0x30` (3976ZS1) | `0x63740` | своя |

✅ **Наш `0x2e` идёт в ветвь `0x63680`**, ту самую, где число слов
`0x238ed` = **145 581**.

## 41.3 Какая модель

`0x63680`…`0x636dc`:

```
w8 = 0x0003d40 (250 688 — предел)
w9 = 0x000238ed (145 581 — число слов)   → *число_слов = w9
если w9 > w8 → 1003
x8 = PTR из GOT
memcpy(куда, x8, w9 × 4)                  = 582 324 байта
```

⚠️ **Размер `DubaiB16BIT` по `readelf` — 582 580 Б**, а переносится
**582 324 Б** (разница 256 Б = 64 слова). Значит **в модель тела идёт
582 324 байта**, а 256-байтовый хвост символа не копируется — это
**согласуется**, а не противоречит: `число_слов` и длина символа — разные
числа, и копируется именно `число_слов`.

✅ Имя символа в этой ветви подтверждено релокацией: слот
`0xd0d90` → `R_AARCH64_GLOB_DAT … DLWeightLightDubaiB16BIT` (единственный
символ на 145 581 слово).

## 41.4 Итог по весам

| вид | что грузится для `0x2e` | число слов |

| **0** | **`DLWeightLightDubaiB16BIT`** | **145 581** |

✅ Наш Rust грузит ровно то, что сток для вида 0. `goodix.rs` пишет
`0x238ed` — столько же. **Совпадает.**

⚠️ Осталась мелочь, не влияющая на путь: слот GOT в ветви надо сверить
дословно (один `readelf`), но 145 581 слово в образе есть только у одного
символа, и это `DubaiB16BIT`.

## 41.5 Что это меняет в открытых вопросах

* Пробел №1 из [40](40-chto-ostalos.md) — **закрыт**.
