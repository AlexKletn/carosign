## 31.4 Что в тексте осталось «предположением» — и помечено

Единственное место, где предположение допустимо, — **абсолютные
миллисекунды** задержек питания и сброса ([28](28-zaderzhki-i-hz.md)):
в стоке они заданы множителем `__const_udelay`, единица в мс без `HZ` не
переводится. Доказаны только порядок и отношения.

⚠️ Всё остальное в разделах 00–30 либо имеет адрес в двоичном, либо прямо
помечено «не разобрано». Догадок «по сходству» в тексте нет.

## 31.5 Что это значит для реализации

Полный список того, что обязан делать наш код, — [10](10-rust-dolzhen.md)
и [16](16-posledovatelnost.md). Самое важное, что выяснил разбор:

1. **Запись отпечатка** идёт не «просто 1007»: `1006` → `1007` (с HAT и
   `+0x6a`) → на `1016` с маской `0x80` → `1012` при `samples_remaining=0`
   → `1008`. Без `1012` шаблон на диск не попадает.
2. **Один `1016` на один край**, повторы только по ступеням `4`/`5`.
3. **Сброс в стоке**: удержание → питание → пауза → импульс `1 → 0`.
   Наш C — другой фронт.
4. **Приложение загружает только proba**; Rust его не трогает, а берёт id.
