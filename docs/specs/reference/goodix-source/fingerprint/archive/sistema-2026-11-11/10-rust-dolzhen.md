# 10 — Что обязан повторить Rust (сводка)

Список — как проверочный лист. Каждый пункт имеет источник в C-версии или в
двоичном стоке.

## A. Договор с приложением Goodix

1. Тело команды — в DMA-буфере (`/dev/dma_heap/system`), размер ≥ объявленной
   длины в заголовке; синхронизация `DMA_BUF_IOCTL_SYNC` до и после. ✅SRC
2. Заголовок: `cmd_id` в `+32`, длина в `+36`, адрес тела — 32-битным словом
   в начале заголовка, старшая половина ноль, флаги в `+4` не трогать. ✅SRC/✅BIN
3. Ответ: 64 байта заголовка, **два** статуса: `+0` результат, `+4` ошибка
   канала. ✅BIN
4. Путь `LOAD_APP goodixfp` → id приходит от proba; `APP_LOADED_QUERY` не
   используется. ✅SRC
5. Порядок открытия: питание/сброс → `DETECT_SENSOR` (544) → `INIT` (344) →
   условный `1016` (`+0x4FF9C=2`) → `INIT_FINISHED` (100) → модель `1111` →
   группа `1014`. ✅SRC/✅BIN
6. `DOWNLOAD_CFG` (1004) — **не слать**: ответ `1000 +100` указывает пропуск.
   ✅MSR
7. Модель фильтра для серии 46 — символ `DLWeightLightDubaiB16BIT`, длина
   `0x8e3b4`, SHA-256 сверен; отказ при другой серии/размере. ✅SRC

## B. События

8. Регистрация получателя: `GF_IOC_INIT` (портид) → `GF_IOC_ENABLE_IRQ`, в
   этом порядке. ✅SRC (найдено по сломанному поведению)
9. Netlink unit 29, payload `[1]`. ✅SRC
10. Один край → один `1016`; серии внутри нет (так и в стоке). ✅BIN
11. Тело `1016` — `0x4FFA8`, между вызовами сохраняется. ✅BIN
12. Разбирать маску `+96` и операцию `+100` **отдельно**; операция `1` —
    не «продолжение». ✅BIN
13. Успех — `1086` один раз; `1006` — несовпадение только на ветке
    распознавания при маске `0x80`. ✅BIN
13a. После `1086` читать флаги `+0x74`/`+0x75` и, если подняты, слать
    `1012 SAVE` и `1085 UPDATE_STITCH`. ✅BIN
14. Время сеанса ограничивать; по истечении — `1009` (отмена), затем
    `GF_IOC_DISABLE_IRQ`. ✅SRC

## C. Служба слушателей (FS/GPFS/RPMB)

15. Один владелец `/dev/spinel-lstnr`; `mmap` трёх копий (FS `pgoff=0`,
    RPMB `1`, GPFS `2`); ответ `DONE(ret)` не позже 5 с. ✅SRC
16. FS: `GET_ERRNO` отдельно от `ret`; пути ремапятся двумя корнями. ✅SRC
17. GPFS: буфер `0x7e000`; команды **0…3** (полный путь) и 4…11 (с корнями);
    резервная копия по флагу `@0x10c`; `O_SYNC`, режим `0600`. ✅SRC/✅BIN
18. RPMB: устройство по `:49476`; геометрия из sysfs (`sectors = blocks/2`);
    запись **двумя фазами** (данные, затем результат). ✅SRC/✅BIN

## D. Чего Rust делать НЕ должен

19. Не загружать `cmnlib`, `cmnlib64`, `goodixfp`, `keymaster64` — это
    делает proba при `load_keep`/`load_km`. ✅SRC
20. Не «продолжать» `1016` с тем же телом по шагу — это была ошибка 10 ноября,
    снята разбором `gf_hal_irq`. ✅BIN
21. Не работать с `SET_MEM_PARAM` — шим его игнорирует. ✅SRC
22. Не выгружать модули отпечатка и не перерегистрировать слушатели в живой
    загрузке. ✅Наблюдение

## E. Порядок проверки на железе (как это работало)

1. `tools/spinel-fp-moduli.sh` — модули в порядке `proba → шим → датчик`.
2. `tools/spinel-najti-obshodom.sh` — адрес.
3. Одна команда `--native-detect`: оба статуса 0.
4. `--native-init`, `--native-finish-init`, `--native-filter-model`.
5. Сеанс распознавания — с пальцем по приглашению, не вслепую.
