# 05 — Демон: GPFS (слушатель `0x7000`)

Часть `spinel-lstnrd.c` ✅SRC. Назначение: TZ читает и пишет файлы доверенного
хранилища (шаблоны отпечатка). Это то, чем снимается ошибка записи шаблона
`1035` при регистрации.

## Буфер и число

* Размер — **`0x7e000`** (504 КБ) — сток `libdrmfs.so` регистрирует столько
  ✅BIN (@`0x5a7c`).
* Каркас запроса: `cmd(u32)@0`, `path[256]@4`, второе поле пути `@0x104`,
  смещение `i32@0x104`, длина `u32@0x108`, признак резервной копии `u32@0x10c`,
  данные — с `@0x110` (для записи).
* Ответ кладётся в тот же буфер: `cmd@0`, `error(int)@4`, а для чтения/записи
  ещё `count(u32)@8`; данные чтения — с `@12`.

## Номера команд — поколение имеет значение ✅BIN

```
cmd = group * 4 + op,  op: 0 чтение, 1 запись, 2 удаление, 3 переименование
```

* `libdrmfs.so` `@0x5c3c–0x5c50`, @`0x5cd8–0x5cf0`: сток планшета шлёт
  **команды 0…3** (полный путь, группа 0) — перенос с Nord4 ждал 4…11 и
  отверг реальный запрос.
* `cmd == 12` — версия: ответ `version=2@+4`, `ok=0@+8`.

## Корни по группам

| group | префикс |
|---|---|
| 0 | `""` (полный путь) |
| 1 | `data/vendor/tzstorage/` |
| 2 | `mnt/vendor/persist/data/` |

Имя проверяется: пустое, длиной `NAME_LEN` или с `..` в любом сегменте —
`EINVAL`.

## Поведение записи ✅SRC

1. `mkparents(path)` — создаёт каталоги.
2. Если `backup != 0` — `gpfs_backup()`: `path.bak` получает текущее
   содержимое, `fsync`, ошибки не глотаются.
3. `pwrite(fd, buf + 0x110, count, offset)`, `O_CREAT|O_RDWR|O_SYNC|O_CLOEXEC`,
   режим `0600`.
4. Пределы: `0 ≤ offset`, `count ≤ 500 КиБ`, `count ≤ bufsize − 0x110`.
5. Любая ошибка: `error` и `count=0` в ответе, данные не пишутся.

## Требования к Rust

* Поддержать **оба поколения номеров**: 0…3 (полный путь, наш планшет) и
  4…11 (с корнями) — Nord4 и older/newer сток.
* Резервная копия — по флагу `@0x10c`, `fsync` обязателен.
* `O_SYNC` и режим `0600`: файл — защищённый шаблон, не обычная запись.
