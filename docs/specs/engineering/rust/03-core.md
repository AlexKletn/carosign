# 03. `carosign-core`: доменные типы и инварианты

**Role:** pure library, `#![forbid(unsafe_code)]`; not an async runtime, storage service, logger or IPC protocol.

## Modules

```text
src/
  lib.rs
  ids.rs                     # typed IDs, stable encodings
  identity.rs                # SubjectRef, AuthorityId, CallerBindingRef
  device.rs                  # DeviceIdentity, Locator, Epoch, Authenticator
  provider.rs                # PackageId, InstanceId, Descriptor
  modality.rs                # fingerprint now, extensible modalities
  capabilities.rs            # declared functional features
  enrollment.rs              # EnrollmentRef, State, generation
  operation/
    mod.rs                   # OperationKind, context
    verification.rs          # VerificationContext, outcomes
    mutation.rs              # MutationIntent, result, phases
    cancellation.rs          # cancel receipt/outcome
  evidence.rs                # opaque evidence handles, claims
  assurance.rs               # assessment refs, not self-asserted trust
  authorization.rs           # opaque grant ref, scope, purpose
  resource.rs                # ResourceSet, LeaseId, state
  error.rs                   # domain errors; no errno/protobuf status
  limits.rs                  # domain length/count constraints
```

## Primary types

```rust
pub struct SubjectRef { pub authority: AuthorityId, pub id: SubjectId }
pub struct AuthenticatorRef { pub id: AuthenticatorId, pub epoch: DeviceEpoch }
pub struct EnrollmentRef { pub id: EnrollmentId, pub authenticator: AuthenticatorId, pub generation: EnrollmentGeneration }
pub struct OperationContext { pub id: OperationId, pub owner: OwnerRef, pub subject: SubjectRef, pub authenticator: AuthenticatorRef, pub purpose: Purpose, pub deadline: Deadline }
pub enum VerificationOutcome { Matched(EvidenceRef), NotMatched, NoSample, Cancelled, Failed(VerificationFailure) }
pub enum MutationOutcome { Committed(EnrollmentRef), NoChange, NeedsReconciliation(MutationId), Failed(MutationFailure) }
```

`Matched` ≠ authorized login; the result is not an Authority grant. `EvidenceRef` identifies scoped evidence held inside trusted runtime; raw token/data are not implicitly returned to caller.

## Invariants

1. All IDs have one canonical byte representation and bounded lengths. Use newtypes; no accidental cross-use between `OperationId` and `EnrollmentId`.
2. `SubjectRef` is scoped to an external authority; Linux uid or Veles profile ID is converted outside core.
3. `AuthenticatorRef` includes an epoch; stale results are invalid on epoch change.
4. `EnrollmentGeneration` is monotonic for changes managed by a registry. It does *not* assert hardware anti-rollback.
5. `DeviceLocator` is ephemeral, not a persistent identity.
6. Unknown ability/assurance is **not** `Verified`.
7. `CancellationReceipt` is distinct from terminal `Cancelled` or `Quiesced`.
8. `OpaqueEnrollmentRef` is bounded, type- and format-tagged, but is not assumed to be template bytes.

## Constructors / validation

- `OperationContext::new(...) -> Result<_, DomainError>` validates nonzero IDs, subject, purpose, deadlines, epoch.
- `CapabilityDescriptor::validate()` forbids contradictions (e.g., `identify` enabled with undefined matching mode); does not grant trust.
- `EnrollmentRef::with_next_generation(current, ...)` checks overflow; generation changes are persisted by repository, not generated by provider.
- `ResourceSet::canonicalize()` de-duplicates claims and orders them by stable ResourceId to avoid deadlock in multi-resource acquisition.

## Error taxonomy

`InvalidIdentity`, `InvalidScope`, `StaleEpoch`, `DeadlineExpired`, `CapabilityMissing`, `ConflictingGeneration`, `InvalidStateTransition`, `LengthLimit`, `UnknownAssurance`. Convert from errors at adapters; no `std::io::Error` or `tonic::Status` in public core signatures.

## Tests

Round-trip identifier encodings; rejected stale epochs; multi-authority SubjectRef collision; generation overflow; `Matched` never converts to authority result without evaluation; canonical ResourceSet order. Pure and deterministic.
