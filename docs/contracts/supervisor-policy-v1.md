# Административная политика supervisor v1

Это внутренний формат разбора, ещё не подключённый к запуску службы. Политика
не заменяет `package.toml` и профили провайдера и сама не является подтверждением
происхождения или разрешением запуска.

Документ UTF-8 TOML размером не более 65536 байт содержит только перечисленные
обязательные поля. Дубли и неизвестные поля отвергаются.

```toml
schema = 1
package = "org.example.provider"
version = "1.0"
profile = "default"
architecture = "x86_64"
executable = "bin/worker"
uid = 1001
gid = 1001
memory_bytes = 67108864
cpu_quota_us = 50000
cpu_period_us = 100000
processes = 2
runtime = ["lib/runtime.so"]
syscalls = [0, 1]
```

Значения примера не являются разрешённым профилем. `package` — идентификатор
из манифеста; `profile` — имя профиля; пути относительны и не содержат пустых,
`.` или `..` компонентов. `architecture` должна совпадать с архитектурой
процесса, поскольку номера в `syscalls` зависят от архитектуры. Нулевые UID,
GID и лимиты не допускаются. Дубли путей и вызовов запрещены. Список runtime
может быть пустым, список вызовов — нет. Номера вызовов и лимиты должны быть
утверждены системной политикой для соответствующего runtime.
Базовая политика не разрешает `socket`, `socketpair` и вызовы `io_uring`:
последний может выполнять создание сокета в обход фильтра отдельного вызова.
Уже переданный приватный канал при этом используется обычными вызовами обмена.

До использования необходимы сверка с манифестом и системным реестром,
подтверждение происхождения установленного артефакта и неизменности всех
используемых файлов. Проверка владельца, простой хеш и валидный TOML этих
гарантий не дают. Production-источник и supervisor пока не подключены.

Внутренняя точка `installation::prepare` сверяет запись источника по трём
идентификаторам (`PackageId`, `ProviderId`, `ProfileId`), а затем проверяет
измерение fs-verity для policy, манифеста, профиля, исполняемого файла и каждого
runtime-файла на удерживаемом дескрипторе. Манифест и профиль разбираются
существующими разборщиками runtime; состав сверяет имена, версию и пути. Перед
выдачей файлов источник обязан повторно подтвердить всю запись. Тестовый
источник и подставной измеритель применяются только в испытаниях.

На данный момент системный источник записей отсутствует и возвращает
`InstallationUnavailable`; точка не запускается основным циклом `carosignd`.
Наличие этого кода не означает работу штатного supervisor или доказанное
происхождение установки. Успех `FS_IOC_MEASURE_VERITY` на поддерживаемой
файловой системе ещё не испытан: обычный файл проверенно получает отказ.
