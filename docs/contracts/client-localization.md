# Локализация и стили CaroSign

Публичный протокол передаёт типизированные состояния и события захвата.
CaroSign CLI и PAM выбирают формулировку на стороне клиента через
`carosign-l10n`. Будущие расширения Plasma и GNOME и самостоятельные
клиенты могут использовать те же ключи и каталоги Fluent. Для клиента
на Rust крейт предоставляет `Preferences` и `Localizer`. Клиент на другом
языке может загрузить системные `.ftl` своим Fluent-движком.

Совместимый интерфейс fprintd передаёт стандартные D-Bus-статусы.
Их пользовательские формулировки выбирает окружение рабочего стола.

## Выбор каталога

Язык и стиль выбираются независимо. CLI читает первую непустую переменную
из `LC_ALL`, `LC_MESSAGES` и `LANG`. PAM сначала проверяет переменные
в контексте текущего PAM-вызова и использует окружение процесса для
отсутствующих значений. Клиент может передать язык и стиль явно через
`Preferences::new`. Стиль выбирается через `CAROSIGN_STYLE`. Идентификатор
стиля состоит из строчных латинских букв, цифр и дефисов, до 32 символов.
`default` означает базовые формулировки.

Для `ru_RU.UTF-8` и `w40k` поиск каждого сообщения идёт в таком порядке:

1. `/usr/share/carosign/locales/styles/w40k/ru-RU/main.ftl`
2. `/usr/share/carosign/locales/styles/w40k/ru/main.ftl`
3. `/usr/share/carosign/locales/base/ru-RU/main.ftl`
4. `/usr/share/carosign/locales/base/ru/main.ftl`
5. Встроенный английский каталог для CLI и PAM. Пакет CaroSign также
   устанавливает английский каталог в `base/en/main.ftl` для внешних клиентов.

Каталоги загружаются при создании локализатора. Отсутствующий или
некорректный перевод пропускается. Системные каталоги и их родительские
директории принадлежат root. Файлы и директории доступны для записи
только владельцу. Символьные ссылки, управляющие символы в готовых
сообщениях и каталоги больше 256 КиБ отклоняются.

## Пакеты и ключи

В [рецепте Arch](../../packaging/arch/locales/PKGBUILD) каждый каталог
устанавливается отдельным пакетом. Собирайте их командой `makepkg` из
`packaging/arch/locales` в исходном дереве.

- `carosign-locale-ru`
- `carosign-style-w40k` для английского и русского
- `carosign-style-tes` и `carosign-style-borg` для английского
- `carosign-style-soviet` для русского

[Английский каталог](../../crates/clients/carosign-l10n/locales/en.ftl)
перечисляет ключи и аргументы для уже подключённых сценариев. Стиль
может переопределить часть ключей. Например, `place-finger` не принимает
аргументов, а `tty-verifying` принимает `attempt` и `seconds`.
Имена ключей и аргументов одинаковы для всех языков и стилей. Формулировки
должны сохранять смысл действия и исхода.
