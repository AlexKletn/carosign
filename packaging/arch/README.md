# CaroSign для Arch Linux ARM

Это испытательный установочный состав, не подтверждающий готовность выпуска.
Пакет содержит службу, посредник, клиент, модуль PAM и отдельный
fprintd-совместимый адаптер. Он не содержит провайдера и не меняет PAM,
не создаёт базу и не запускает службы. После установки нужны политика,
профиль совместимого провайдера и явная инициализация новой базы; порядок
описан в `systemd.md` и `linux-provider-profile.md` этого каталога.
Поддержка регистрации, удаления и конкретного аппаратного провайдера зависит
от установленного состава; пакет сам по себе их не подтверждает.

Если результат регистрации или удаления после отправки остался неизвестен,
затронутая область остаётся закрытой до сверки; другие области продолжают
работать. Команда `QueryMutation` предусмотрена контрактом, но её исполнение
для восстановления в системном составе пока не подключено; мок возвращает
`QueryUnsupported`. Удаление базы не восстанавливает состояние провайдера и
не является процедурой сверки.

Сборка на хозяине:

```sh
CAROSIGN_SYSROOT=/абсолютный/путь/к/aarch64-sysroot \
  sh tools/build-arch.sh /абсолютный/путь/к/carosign.pkg.tar.zst
```

Для дополнительной проверки библиотек целевой системы укажите
`--check-rootfs /абсолютный/путь/к/rootfs`. Эта проверка не запускает код и
не подтверждает совместимость ядра, работоспособность провайдера или PAM.
Сборка берёт зависимости Cargo из локального кеша и требует установленный
кросс-компилятор, sysroot и makepkg. Проверять её следует на отдельной
системе с запасным способом входа.

Команда `sh tools/check-arch-reproducibility.sh` дважды собирает пакет и
сравнивает байты. До её завершения исходники и окружение менять нельзя;
совпадение не доказывает воспроизводимость на другом toolchain или хосте.

Для обычной нативной сборки через `makepkg` можно создать отдельный локальный
исходный снимок и `PKGBUILD` с его контрольной суммой:

```sh
sh tools/create-arch-source.sh /абсолютный/путь/к/новому-каталогу
cd /абсолютный/путь/к/новому-каталогу
makepkg -s
```

Снимок содержит исходники платформы, а не собранные ELF; `makepkg` вызывает
Cargo и проверку workspace. Нужны соответствующие пакеты для сборки и доступ
Cargo к зависимостям, если они не сохранены локально. Это локальный снимок,
не опубликованный подписанный исходный выпуск; указанная сумма защищает от
случайного изменения, а не подтверждает его происхождение. Для независимой
проверки рекомендуем сборку в чистом Arch Linux ARM chroot.

## Графический клиент CaroSign

Пакет `carosign-ui` устанавливает приложение на Obscur Kit и пункт
в меню. Для инвентаризации провайдеров требуется `carosign` версии `0.1.0-2`
или новее и разрешение `inventory` в политике службы.

Сборка для AArch64 из корня проекта с D-Bus в целевом sysroot и соседним checkout Obscur Kit v2:

```sh
CAROSIGN_SYSROOT=/path/to/aarch64/sysroot \
  sh tools/build-arch-ui.sh "$PWD/target/dist/carosign-ui-0.1.0-1-aarch64.pkg.tar.zst"
```
