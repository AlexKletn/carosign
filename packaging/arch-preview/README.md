# Проверочный пакет CaroSign для Arch Linux ARM

Это дорелизный пакет для проверки состава и удаления в изолированной системе.
Рабочая служба не реализована: `carosignd` и broker не готовы, адаптер fprintd
не предоставляет устройства, а PAM не выполняет биометрический вход. Пакет не
подтверждает совместимость с целевой системой и не предназначен для входа.

Пакет содержит только файлы программы и два статических systemd unit без
секции `[Install]`: установка не включает и не запускает их. Пакет не меняет
`/etc/pam.d`, не устанавливает ключи, не создаёт хранилище и не замещает
системный fprintd посредством D-Bus activation. Unit-файлы являются лишь
макетами: настройки изоляции, проверенный запуск и взаимодействие процессов
пока не готовы. Системная служба fprintd не должна одновременно владеть тем же
именем шины и устройством.

До будущего выпуска нужны проверка состава библиотек целевой системы,
проверенные полномочия и полная приёмка. Сборка из данного PKGBUILD потребляет
уже собранные файлы; без отдельно зафиксированного toolchain она не доказывает
воспроизводимость компиляции.

При сборке можно явно потребовать статическую проверку всех пяти ELF по
полученному отдельно дереву целевой системы. При отсутствующей зависимости
или загрузчике пакет не публикуется:

```sh
sh tools/build-arch-preview.sh /путь/к/новому-пакету.pkg.tar.zst \
    --check-rootfs /путь/к/rootfs
```

Без `--check-rootfs` проверка целевой системы не выполняется. Проверять надо
именно представительное дерево целевой системы, а не сборочный sysroot:
результат по последнему не подтверждает библиотек установленной системы.
Даже успешная статическая проверка не подтверждает происхождение дерева,
совместимость ядра, работоспособность или безопасность входа.

Для проверки содержимого после установки из корня подготовленного дерева:

```sh
cd /путь/к/корню
sha256sum -c usr/share/doc/carosign-preview/SHA256SUMS
```

Проверка сумм обнаруживает изменение файлов относительно пакета; она не
подтверждает происхождение пакета, зависимости или работоспособность службы.
